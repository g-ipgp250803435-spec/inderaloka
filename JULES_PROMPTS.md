# Cadangan Tugasan Jules

## Kandungan dan halaman

- Tambah halaman pelaburan negara dengan sektor, insentif dan proses permohonan.
- Tambah profil semua anggota kabinet dan fungsi carian kabinet.
- Tambah halaman wilayah dengan route dinamik `/wilayah/[slug]`.

## Content Studio

- Tambah editor drag-and-drop bagi susunan blok halaman.
- Tambah sejarah versi menggunakan Git commits yang sedia ada.
- Tambah preview draf dalam iframe sebelum penerbitan.
- Tambah akses berperingkat untuk editor, reviewer dan publisher.

## Portal awam

- Tambah sokongan bahasa Inggeris dengan route `/en`.
- Tambah data terbuka dalam bentuk carta yang accessible.
- Tambah borang maklum balas tanpa menyimpan maklumat sensitif.
- Tambah command palette untuk navigasi pantas.

## Kualiti

- Tambah Playwright smoke tests untuk semua route.
- Tambah unit tests bagi auth cookie dan GitHub commit helper.
- Audit WCAG 2.2 AA dan baiki semua isu yang ditemui.
